# 🐾 Pawfect Corner – Pet Shop Website

## About the Project
Pawfect Corner is a responsive pet shop website designed to provide pet owners with a friendly and easy shopping experience. It showcases pet products, services, customer reviews, and useful information for pet owners.

## Features
- **Responsive Design:** Works on desktop, tablet, and mobile.
- **Product Categories:** Dogs, cats, birds, fish, and small pets.
- **Product Filtering:** Filter products using CSS without JavaScript.
- **Pet Services:** Grooming, health checks, pet hotel, and training.
- **Customer Reviews:** Displays customer feedback.
- **FAQ Section:** Answers common questions.
- **Newsletter Section:** Allows visitors to enter their email.
- **Dark Mode:** Automatically adapts to the device's color scheme.
- **Animations:** Smooth transitions and interactive hover effects.

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Fredoka and Nunito)

## How to Run
1. Download or clone the project.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in your web browser.
4. Explore the website!

The website uses a colorful and playful design with responsive layouts, rounded cards, animations, and pet-themed elements.
